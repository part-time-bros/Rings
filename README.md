# Rings

Configuration for the [TradingView MCP server](https://github.com/atilaahmettaner/tradingview-mcp)
— real-time market data, technical analysis, screeners and backtesting for
stocks, crypto, forex and futures.

`.mcp.json` declares the server at project scope, so Claude Code sessions
started in this repo pick it up automatically. See
[docs/tradingview-mcp.md](docs/tradingview-mcp.md) for setup, the optional
Marketaux API key, and the full tool inventory.
